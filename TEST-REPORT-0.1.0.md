# Отчёт проверки M1 — 0.1.0-m1

Дата: 19 ноября 2026 года.

## Среда

- Сервер: Linux, Python 3.13.
- FastAPI 0.115.12, Uvicorn 0.34.2; остальные версии зафиксированы в requirements.txt.
- Браузер: Chromium, автоматизация Playwright.
- Windows 10 Pro 22H2 пользователя: **не проверено**.
- Получение установочных wheels зависимостей для CPython 3.12 / Windows x64 проверено через pip download. Это проверка доступности пакетов, не запуск на Windows. Пакет colorama проверен отдельно.

## Серверные тесты

Команда: `python -m pytest -q`.

**Результат: 12 passed.** Есть предупреждение устаревшего алиаса anyio в тестовом клиенте Starlette; падений нет.

1. Первая настройка, требование подтверждения папки, сохранение/чтение черновика и сообщения, отказ при устаревшей ревизии, запрет повторной настройки работающего пространства.
2. Отказ без локального токена, чужой Host/Origin, отсутствие разрешения CORS для чужого сайта, CSP с nonce.
3. Реальный импорт байтов, проверка SHA-256, обратное скачивание, отказ для небезопасного имени, резервная копия и восстановление, отказ для повреждённого ZIP.
4. Событие и текстовый результат на диске; архив только для чтения, восстановление проекта, отказ для 31 февраля.
5. Запрет второго процесса одного пространства, symlink и выхода за папку, NTFS ADS-синтаксиса пути.
6. Повторное открытие SQLite после закрытия объекта службы: данные остаются.
7. Небезопасный путь в резервном архиве не изменяет рабочие данные.
8. Нельзя зарегистрировать фиктивный импортированный файл или выдать синтетическое assistant-сообщение за ответ модели в M1.
9. Если страховочная копия перед восстановлением не создаётся, текущие данные остаются неизменными.
10. Запись и чтение 500 независимых проектов с разными ID.
11. Изменённый вне приложения материал не скачивается как неповреждённый и не попадает в успешно завершённую копию.
12. Пользовательская дата проекта не меняет дату создания; редактирование даты создания отклоняется.

В Linux проверены POSIX symlink и блокировки. Специфические Windows junction/reparse points/NTFS hardlinks требуют отдельной проверки в целевой ОС.

## Браузерный сценарий

Файл: tests/ui.cjs. Выполнен на отдельном пустом тестовом пространстве, не на данных предпросмотра.

Результат: PASS.

- Первый выбор пространства через интерфейс.
- Запись сообщения без вымышленного ответа модели; восстановление после перезагрузки.
- Черновик сохраняется при переключении вкладок.
- Настоящий импорт TXT, последующее скачивание с точным сравнением байтов.
- Создание текстовой заметки, просмотр сохранённого результата.
- Создание события с датой и временем, сохранение после перезагрузки.
- Архив блокирует ввод; будущее невыполненное событие остаётся в общем календаре.
- Восстановление проекта из архива.
- Новый проект не содержит чужой переписки и черновика.
- При ширинах окна 360, 768 и 1440 px не обнаружен горизонтальный выход корневого документа за окно.
- Во втором окне устаревшая ревизия даёт явную ошибку, а не молчаливое затирание данных первого окна.
- Необработанных ошибок JavaScript в сценарии не обнаружено.

Дополнительно реальным запуском CLI проверены повторный запуск без второго процесса и остановка через локальный API. Тестовый процесс завершился с кодом 0.

## Не проверено и не заявляется

- Запуск BAT и весь пользовательский сценарий на Windows 10.
- Уведомления, работа после сна Windows, автозапуск, нативная печать, Word/LibreOffice, DPAPI — не реализованы на этапе M1.
- API моделей, платные запросы, источники права, извлечение текста из документов — не реализованы.
- Сбои питания и аппаратные отказы диска; полнота сохранности при всех сценариях аварийного завершения.
- Полный penetration test, доступность интерфейса по всем WCAG-сценариям, производительность на целевом Ryzen/8 ГБ.
- Работа нескольких пользователей и запуск пространства на сетевом диске.

M1 — первая тестовая сборка локальной основы. Она не закрывает все пункты полной V1 из ТЗ. Перед реальными материалами необходима пользовательская приёмка на Windows и отдельный этап подключения моделей.

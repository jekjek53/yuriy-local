# Проверка 0.6.0-m4

## Статус

Реализация двух блокеров подготовлена для пользовательской проверки. **Не акт приёмки V1.** Рабочая 0.5.1 на ноутбуке не обновлялась, доступ к ноутбуку не подразумевается.

## Автоматические проверки

- Linux / Python 3.13: **190 passed, 3 skipped**, унаследованное предупреждение Starlette/AnyIO. Пропуски Windows DPAPI/junction/Job Object не считаются выполненными тестами. Существующие M1–M4 проверки сохранены; старые тестовые запросы DOCX сознательно переведены на поля, старый универсальный контракт создания больше не принимается.
- UX-DOCX: 27 новых случаев, включая позднюю проверку чтения/backup/restore старого DOCX без перепаковки. Первичный этап до этой дополнительной проверки — 160 passed / 3 skipped; не складывать эти запуски как разные тесты.
- M4-SEC-01: 29 новых случаев, включая отсутствие автоматического исправления старого ошибочного события.
- `node --check`: локальные модули `m4.js` и `legal-drafts.js`.
- Новые зависимости docxtpl/Jinja2/MarkupSafe закреплены; доступность wheels для Windows CPython 3.12/3.13 x64 проверена скачиванием. Это не запуск Windows-инсталляции.

## Чистая распаковка поставки

Из проверочного ZIP выполнена отдельная распаковка вне дерева разработки. В ней повторены **190 passed, 3 skipped**, проверены версия `0.6.0-m4` и все **78/78** записей манифеста. На шести независимых mock-пространствах этой чистой распаковки повторены все шесть Chromium-сценариев выше — PASS. Итоговые изменения после этого только документальные: настоящий раздел отчёта и итоговая упаковка. Код, шаблоны и тесты не менялись.

Архив не содержит `.venv`, кэшей, рабочих пространств, тестовых баз или API-ключей. Исходный поставленный ZIP 0.5.1 проверен по SHA и не изменён. Созданные проверочные службы остановлены; посторонний процесс на 8765 не трогали.

## Ручные структурные проверки и ограничения

Доверенные шаблоны сохранены внутри программы; их контрольные суммы проверяются. Параметры страницы, стилей, таблицы без границ, нумерации и отдельного разрыва страницы проверены по OOXML. Это не обещание визуально проверенной Word-пагинации. Скриншоты интерфейса DOCX/карточки секретаря просмотрены.

На данном headless Chromium для blob-download `suggestedFilename` иногда возвращается `download`; проверены реальный аргумент `a.download`, серверное имя и формирование временной копии Windows через заглушку. Фактическое русское имя на ноутбуке входит в ручную приёмку.

Реальное открытие Office, переносы/пагинация и печать не проверены. LibreOffice не устанавливался. Сон Windows не проверен; прежняя имитация перерыва службы не считается сном. Пользовательские результаты Windows 0.5.1 (137/137 и принятая компоновка) остаются историей, не автоматически переносятся на 0.6.0.

Нет обучения, JSONL-корпуса, массового скачивания, скрытой передачи корпуса, голоса или автозапуска. Не заявляется независимый аудит безопасности.

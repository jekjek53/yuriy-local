## Новые 12 тестовых случаев

Отмена после заведомо полученного текста: точный префикс остаётся в БД. Отмена до первого текста: пустой ответ имеет честное объяснение. Настоящий OpenAI-адаптер с httpx.MockTransport/AsyncByteStream: отмена закрывает поток и сохраняет видимый префикс. Поздняя запись checkpoint не сокращает текст и не возвращает cancelled в running. Неуспешные задания исключаются из следующих API-вызовов без удаления истории. Успешная пара не распадается из-за бюджета. Отдельный лимит D не меняет лимит B и поддерживает наследование общего. Разобраны content-parts, terminal message, reasoning-only, неподдержанное содержимое. Reasoning-only завершение остаётся errorCode=empty, один вызов без повтора; текст reasoning не сохраняется.
